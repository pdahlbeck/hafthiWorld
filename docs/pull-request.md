Adds the first small household/food step from #1: **order home supply → wait for real stored grain → carry each sack to an owned door-side pantry → use delivered food over simulation time**. H and a native button place an idempotent standing order. The existing worker belongs to Home 1; food is removed from shared storage only at pickup, becomes household-owned only after unloading, and cannot be consumed while still stored/shared or carried. Available home supply takes priority over a new production job; current tasks finish first and the worker returns to the shared-store approach before accepting another job.

This is a stacked PR based on #6 (`codex/sheep-wool-loop`), still open and dependent on #5/#4. Merge the predecessors first, then retarget this PR to main. The diff adds one household foundation, not multiple autonomous families.

The ration clock starts after the first actual delivery and uses one owned unit per 40 simulation seconds. Empty due intervals report food shortage without negative inventory or consuming another home's stock. The environment now advances once per world FixedUpdate, independently of worker count; simulation clocks are not tied to an individual worker. The same grain entities move through shared store/carried/home/consumed states; consumed meshes hide and keep their IDs. The toolbar wraps into two rows, and the scene's tree picking excludes the whole reserved UI area.
