The same finite six timber units now compete between construction and fuel; the order does not fell trees or create wood.

Pickup changes stored timber to carried; only unloading makes it household-owned fuel. Eligible fuel top-ups precede new seed/food/trade/production jobs, while current work/deliveries finish first and the worker returns via the existing southern approach. Household membership and the three-log target are checked. Installed material, shared stocks, carried logs and another home's fuel cannot be burned.

The home consumes one owned log per **40 actual calendar-winter seconds**. Other seasons pause this clock. Missing due intervals increment a shortage counter without negative inventory or substitute materials. Demand runs from winter onset even without a first delivery and independently of workers/cameras/sun. Long updates derive exact winter time from the existing seasonal calendar. Burned logs hide their meshes but keep their IDs. The HUD exposes owned fuel, target, total burned, missed intervals and remaining winter seconds; no actual fireplace, room-temperature or health model is added.
