Adds the next small farming/livestock slice from #1: **two persistent grazing sheep → order clipping → two wool bundles per sheep → carry each bundle to storage**. C and a strategy button queue the same worker already used by timber and crops. Sheep hold their current positions while awaiting clipping, show a reduced/darker coat afterwards, and resume grazing without moving the fixed wool drop positions. Both cameras read the same animals, cargo and stocks.

This PR is stacked on #5 (`codex/first-crop-loop`), which is still open and itself builds on #4. Merge those predecessors first, then retarget this PR to main. The diff against #5 contains only the sheep/wool slice and its supporting UI, tests and documentation.

Each animal has one finite two-unit fleece. Repeated orders cannot regrow coats, duplicate wool or credit storage before a physical delivery. Existing timber/farm priorities remain, and authored worker waypoints pass around the house and through the pen's open southern approach. The three visible fence sides block walking. All geometry is original, with no dependency changes or breed-specific historical claims. Feed consumption, health, breeding, wool regrowth, spinning and trade remain later work.
