The farm previously had one resident, so coastal work blocked timber, crops and the salt supply chain. This package adds **one-time recruitment, automatic coastal work allocation and two-resident/cargo presentation**. N / Invite helper brings a blue-clad coastal worker into the existing Home 1, walks them from the shore approach to shared storage, then assigns fishing, salting and salted-fish home deliveries. The green founder keeps timber/building, crops/seeds, wool, barter, grain and winter fuel. Both can work and carry at the same time.

A fresh session stays solo until N. Repeated N cannot create a third resident, replace the founder or reset resources. If the founder already owns a coastal catch, processing batch or fish delivery, that complete job and return finishes before the helper takes new coastal work. A single recorded coastal-job owner prevents two residents selecting the same fish/ingredients; the founder stops starting new coastal jobs after invitation. Idle residents have separate rest positions. The trader remains a visitor, not a worker.

Every resident has a stable ID, role, home, task, position and individual cargo. Actor bodies and log/grain/wool/salt/fish meshes now resolve their actual carrier rather than stopping rendering when the worker query has two results. The HUD shows both tasks and the current coastal-job owner. World/calendar/growth/meal/fuel clocks still advance once per fixed tick; they never run once per resident. No dependency changes.
